Programas en Java para DAM con JUnit en Eclipse 🚀

Descripción 📌

Este repositorio contiene una colección de programas en Java desarrollados como parte del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM). Los programas incluyen ejercicios prácticos, proyectos de aprendizaje y aplicaciones de ejemplo para reforzar los conocimientos adquiridos en programación con Java. 🖥️✨ Además, se incluyen pruebas unitarias utilizando JUnit en Eclipse.

Requisitos ✅

Para ejecutar los programas correctamente, es necesario contar con el siguiente software:

Java Development Kit (JDK) versión 8 o superior. ☕

Eclipse IDE con soporte para Java. 🛠️

JUnit 5 para realizar pruebas unitarias. 🧪
